# Next.js 16.2.11 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** อัปเกรด Next.js และ eslint-config-next จาก 16.2.6 เป็น 16.2.11 Stable/Active LTS บน `main` โดยไม่เปลี่ยนพฤติกรรมของแอป

**Architecture:** ใช้ npm ติดตั้งเลขรุ่นแบบ exact เพื่อให้แก้เฉพาะ dependency manifest และ lockfile จากนั้นเปรียบเทียบผล typecheck, lint และ build ก่อนกับหลังอัปเกรด งานนี้เป็น configuration-only จึงใช้ baseline equivalence แทน failing behavior test; หากพบ regression ที่ต้องแก้โค้ด ต้องเพิ่ม regression test ที่ล้มเหลวก่อนแก้

**Tech Stack:** Next.js 16.2.11, React 19.2.4, TypeScript 5, ESLint 9, npm, Windows PowerShell

## Global Constraints

- ทำงานบน branch `main` ก่อนรวม `codex/pdpa-rbac`
- เปลี่ยน `next` และ `eslint-config-next` เป็น `16.2.11` แบบ exact
- คง `react` และ `react-dom` ที่ `19.2.4`
- ไม่ใช้ `@latest`, Preview, Canary, codemod หรือฟีเจอร์ทดลอง
- ไม่แก้ application code หาก baseline และ verification ผ่าน
- Development server ต้องใช้ port `3005`
- ฟังก์ชันหรือกฎธุรกิจที่จำเป็นต้องแก้จาก regression ต้องมีคอมเมนต์ภาษาไทยและ regression test ก่อนการแก้
- ไม่รวม branch PDPA/RBAC และไม่ push ในแผนนี้
